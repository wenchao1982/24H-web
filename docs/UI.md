# 界面设计与功能分布（UI）

> 目标：**chat-first、简洁、克制**的中文工作台。布局借鉴 dsh（DeepSeek Harness）的**三栏 AppFrame**；顶栏移除，状态与控制就近安置；保留**一个强调色**。

## 1. 设计原则

1. **三栏框架**：侧栏 · 主区 · 详情面板；面板可拖拽缩放，空间不足**让步链**先缩详情、再自动关闭。
2. **无全局顶栏**：品牌/状态在侧栏品牌行；模型在输入框；外观与面板开关就地。
3. **侧栏 = 导航 + 上下文列表 + 底部设置**；可折叠为 **56px 轨道**。
4. **详情面板默认关闭**；打开后承载文件/预览/日志/Git。
5. **留白优先、发丝描边、平滑圆角**（见 §12 视觉风格）。
6. **不用 ⌘K 面板**；只保留极少数快捷键。
7. **一个强调色**，仅用于主操作/激活态/运行指示。

## 2. 总体布局：三栏 AppFrame

```
┌───────────────┬────────────────────────────────┬──────────────────┐
│ 24H ▮ v0.21.3 │  会话头  ‹标题›  模型   ⏹   ◧    │  文件 预览 日志 Git │
│ ● 核心  ◦ 渠道 │────────────────────────────────│                  │
│               │                                │   详情面板        │
│ [对话][智能体] │          对话 / 页面            │   (默认关闭)      │
│ [群聊][任务]   │                                │   可拖拽缩放      │
│ [用量]        │                                │                  │
│───────────────│                                │                  │
│ 会话列表       │                                │                  │
│ · 搜索 / 新建  │────────────────────────────────│                  │
│ · 等待审批 ●   │ 输入框 [附件][模型] 发送/停止    │                  │
│ · ...          │ 上下文 18% · 62 tok/s          │                  │
│───────────────│                                │                  │
│ ⚙ 设置  🛡 管理 │                                │                  │
└───────────────┴────────────────────────────────┴──────────────────┘
   侧栏(可折叠 56)         主区                        详情(默认关)
```

**面板几何**（瞬时状态，刷新重置）：侧栏默认展开（宽 ~260px）、详情默认关闭；拖动不可见命中条带缩放侧栏，拖动浮动胶囊缩放详情。

**让步链**（窗口变窄时）：先收缩详情面板 → 仍不足则**自动关闭详情**；侧栏可折叠进 **56px 轨道**（仅图标，悬停出文字）。窗口变宽自动恢复。

## 3. 侧栏

| 区域 | 内容 |
| --- | --- |
| **品牌行** | `24H` + **版本徽标**（如 `v0.21.3`）；`● 核心` 状态灯 + `◦ 渠道` 状态点；**点击核心灯 → 系统升级**（核心 + web 一起） |
| **导航行** | 图标 + 文字：**对话 · 智能体 · 群聊 · 任务 · 用量**（当前项高亮=强调色） |
| **上下文列表** | 随当前区切换、可滚动：对话→会话列表；智能体→agent 列表；群聊→房间列表；任务→任务列表；用量→无列表（隐藏） |
| **底部固定** | `⚙ 设置` · `🛡 管理`（仅 super_admin） |

**折叠行为**：内容淡出 + 控件左移进 56px 轨道（减少动态效果时禁用过渡）。

**会话行状态**（对话区列表）：
- 挂起交互用**琥珀色警告点**（等待审批 / 计划待审 / 等待回答），优先级高于运行指示。
- 运行中用**强调色活动点**。
- 有活动定时任务：标题后一个**轮廓闹钟**图标。
- 搜索：区头按钮展开；标题即时匹配 + 防抖内容搜索（最多 20 条）。

## 4. 主区与会话

**会话头**（仅对话区）：`‹标题›` · 绑定模型 · 停止/后台 · **详情面板开关 `◧`**。

**transcript**：用户/助手气泡 · 工具卡（`tool.start/generating/complete`）· 思考块 · `done/error` · 挂起卡（审批/澄清/sudo/secret）。

**输入框（常驻）**：
- **模型选择器**（就地，切换影响本会话后续）。
- `[附件]`（图片/文件/PDF）、slash 命令、引用 chip。
- **发送 / 停止 / 队列**：空闲主操作=发送；运行中主操作=停止；繁忙时 Enter=加入队列。
- 乐观发送：Enter 清空草稿立即回显；失败按提交顺序合并还原。
- 断线重放：刷新后经 `session.events.since` 恢复挂起状态。

## 5. 详情面板（默认关闭）

| Tab | 内容 |
| --- | --- |
| 文件 | 工作区文件浏览/读取 |
| 预览 | 文件/HTML 预览 |
| 日志 | 读取/过滤 |
| Git | 状态/差异 |

可拖拽缩放；让步链先缩后关；隐藏不销毁（保留滚动/状态）。

## 6. 外观

- **保留一个强调色**（默认建议 `#4d6bfe`，可改）：主操作按钮 / 激活导航 / 运行指示。
- 日/夜切换：侧栏底部或设置「通用」内的 `☀/🌙` 一键切换（`light` / `dark` / `system`）。

## 7. 各区功能分布

| 区 | 侧栏列表 | 主区 |
| --- | --- | --- |
| **对话** | 会话列表（搜索/新建/重命名/删除/恢复） | 会话头 + transcript + 输入框 |
| **智能体** | agent 列表（头像·名称·模型·版本灯·状态） | agent 详情：SOUL / 模型 / Skills / MCP / Toolsets / 版本灯 / 头像；操作：新建/克隆/编辑/删除/导入导出 |
| **群聊** | 房间列表（成员数·最新·needs-you） | 房间内多 agent 对话（@成员 / @user / 线程） |
| **任务** | 任务列表 | Cron 详情 + 新增/暂停/恢复/删除/立即运行 |
| **用量** | —（无列表） | 概览卡片 + 按模型费用 |
| **设置** | 分区列表 | 分区详情 |
| **管理** * | 分区列表 | 用户与角色 / 审计 / 系统运维 |

**设置分区**：模型与密钥 · 渠道 · 用量 · 监控 · 集成（记忆/Webhooks/插件） · 数据与目录 · 系统（升级 + 诊断运维） · 高级。

## 8. 快捷键（无 ⌘K 面板）

| --- | --- |

## 9. 响应式 / 移动端

- 窄屏：侧栏折叠进 56px 轨道或抽屉；详情面板转全屏页；会话列表与对话可切换。
- 主区会话头精简。

## 11. 参考：dsh 的布局决策（本设计的依据）

- **三栏 AppFrame**（`sidebar / conversation / details`）：可拖拽缩放；详情默认关闭。
- **让步链**：窗口变窄先收缩详情，随后自动关闭；侧栏收起保留 **56px 控制栏**。
- **面板几何瞬时**：刷新恢复默认；不写 localStorage。
- **侧栏**：品牌行（mark + 名称 + **版本徽标**）· New Session · 可滚动浏览器 · **底部固定 Settings**。
- **会话行**：挂起交互**琥珀点**（等待审批/计划待审/等待回答）；活动 Schedule 显示**轮廓闹钟**；subagent 来源会话隐藏。
- **输入框常驻**：乐观发送；繁忙时 Enter=Queue；主操作在 发送/停止 间切换。
- **滚动条**是指针可供性：指针不在栏内时透明，离开后滑块保留 ~2 秒。

## 12. 视觉风格（借鉴 dsh）

> 参考 dsh 的 `--dsw-*` 设计系统：单色基调 + 语义 token + 发丝描边 + 平滑圆角 + 字号阶梯 + elevation。

### 12.1 token（语义 alias）

| token | 含义 |
| --- | --- |
| `--ds-bg-base` | 页面底色 |
| `--ds-surface-l1` / `--ds-surface-l2` | 面板 / 浮层表面 |
| `--ds-label-primary` / `--ds-label-secondary` / `--ds-label-tertiary` | 三级文字 |
| `--ds-border-l1` / `--ds-border-l2` | 发丝描边（10% / 12%） |
| `--ds-accent` | 强调色（唯一） |

### 12.2 参考色值

| 用途 | 亮色 | 暗色 |
| --- | --- | --- |
| 底色 | `#ffffff` | `#151517` |
| 主文字 | `#0f1115` | `#f9fafb` |
| 次文字 | `#61666b` | `#cfd3d6` |
| 三级文字 | `#81858c` | `#adb2b8` |
| 描边 | `rgb(0 0 0 / 10%)` | `rgb(255 255 255 / 12%)` |
| **强调色** | `#4d6bfe` | `#4d6bfe` |

### 12.3 描边与阴影

- **0.5px 发丝描边**表示层级；高层级表面 `border: 0` 用描边，**不占布局**。
- 阴影分级：`elevation-soft / panel / prominent`；输入框用更大模糊、更低透明度。

### 12.4 圆角

- **平滑圆角**：`@supports (corner-shape: superellipse(1.5))` 用超椭圆；否则普通圆弧。
- 圆 / 胶囊（头像、按钮）配 `corner-shape: round`。

### 12.5 字号

- 正文默认 **14px**（可调 12–17）；标题/摘要/表格**低一档**；小号文本与代码**固定**等宽。

### 12.6 字体

- 正文：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 代码：`"SF Mono", "JetBrains Mono", "Fira Code", Consolas, Menlo, monospace`

### 12.7 主题

- `light` / `dark` / `system`；**首帧前注入**所选配色，避免闪烁。

## 13. 已定决策

- 保留**一个强调色**（仅主操作/激活/运行指示）。
- **管理**独立入口（仅 super_admin）。
- 一级名 **「群聊」**。
- **监控**独立设置分区。
- **升级不分开**（核心 + web 同一面板，入口在侧栏品牌行核心灯）。
- **无 ⌘K 面板**；外观 = 日/夜一键切换；详情面板默认关闭、可拖拽、让步链自动关。
- **无全局顶栏**（dsh 式）：状态与控制在侧栏品牌行 / 输入框 / 就地。

## 15. 实用体验改进

- **状态用灯/点**，不用文字堆（运行点 / 挂起琥珀点 / 渠道点）。
- **挂起交互行内可见即可处理**（等待审批/回答 → 点开直接答）。
- **乐观发送 + 失败合并还原**（Enter 立即回显，失败按提交顺序还原）。
- **断线重放**：刷新经 `session.events.since` 恢复挂起。
- **运行中主操作 = 停止**（发送/停止同位置切换）；可"转后台"。
- **就地操作**：模型在输入框、面板开关在会话头、外观一点切。
- **键盘优先** + 明确空态 + 支持减少动效。
- **可拖拽**：面板缩放。

## 16. 数据简洁原则

- 列表行只留 **1–2 个关键字段**；次要信息进 hover / 详情面板。
- **渐进披露**：高级项默认收起。
- 统一术语（禁用/启用、运行/停止）；数字格式化（k/M、%、相对时间）。
- **不做数字墙**：用量 = 一句话 + 一张图。
- 同一状态只出现一次（别灯 + 文字 + 徽标重复）。
