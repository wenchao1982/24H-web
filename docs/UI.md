# 界面设计与功能分布（UI）

> 目标：**chat-first 的中文工作台**。一级导航精简；能力按"智能体"归类；配置/集成收进「设置」；顶栏一键切换外观与升级。
> 依据：用户对早期设计的修订（群聊升一级、技能并入智能体、设置收渠道/用量/监控、顶栏升级灯、日/夜切换、右面板图形按钮、去掉命令面板）。

## 1. 总体布局

```
┌──────────────────────────────────────────────────────────────────┐
│ 24H  ● 核心 ready v0.21.3 ▾   ◦ 渠道   模型▾   ☀/🌙   ◧          │ 顶栏
├──────┬───────────────────────────────────────────┬───────────────┤
│ 对话 │  会话列表 │   对话区                        │ 文件 预览 日志 Git│
│ 智能体│          │   气泡 / 工具卡 / 审批卡         │   (◧ 收起)     │
│ 群聊 │          │                                 │               │
│ 任务 │          │  ──────────────────────────     │               │
│      │          │  Composer [附件][模型] 发送      │               │
│ 设置 │          │  上下文 18% · 62 tok/s          │               │
│ 管理*│          │                                 │               │
└──────┴───────────────────────────────────────────┴───────────────┘
```

四个区域：**顶栏** / **左轨（一级导航）** / **主区** / **右侧面板**。（命令面板已移除。）

## 2. 顶栏

| 元素 | 说明 |
| --- | --- |
| 品牌 | 「24H」 |
| **核心灯** | `● 状态 + 版本号`（如 `● ready v0.21.3`）；**点击 → 升级面板**（检查/升级 **核心 + web 应用**） |
| 渠道状态 | 连接状态指示（如 `◦ 渠道 未连接`）；**配置在「设置 → 渠道」** |
| 模型选择器 | 当前会话 / 默认模型；切换影响后续对话 |
| 外观 | **`☀/🌙` 一键切换日间/夜间**（最简，无需下拉） |
| 右面板按钮 | **`◧` 图形按钮**：收起/展开右侧面板 |

## 3. 左轨（一级导航）

| 项 | 说明 |
| --- | --- |
| **对话** | 默认落地页，chat-first |
| **智能体** | Agent/Profile + **该 agent 的 skill / MCP / 模型 / 版本灯** |
| **群聊** | **多 agent 协同**：房间列表 + 房间内多 agent 对话 |
| **任务** | 定时任务（Cron） |
| **设置** | 配置与集成（二级分区，见 §6） |
| **管理** * | 用户与角色 / 审计 / 系统运维（仅 super_admin 可见） |

> 变更：**技能并入「智能体」**（不再单独一级）；**用量 / 监控 / 渠道 移入「设置」**；**命令面板移除**。

## 4. 智能体页（含 per-agent 能力管理）

**列表**：每行 = 头像 · 名称 · 模型 · **版本灯** · 状态。
**操作**：打开对话 · 编辑 · 克隆 · 删除 · 导入/导出 · 新建。

**单个智能体管理（均为 per-agent）**：
- **SOUL**（人格 / 系统提示）
- **模型 / provider**
- **Skills**（启停）
- **MCP servers**（增删启停）
- **工具 / Toolsets**
- **版本灯**（该 agent 的运行时版本 / 健康）
- **头像**

任务：T16.1–T16.5（Agent/Profile）、T7.1/T7.2（skill）、T7.3（toolsets）、T7.4（MCP）。

## 5. 群聊页（多 agent 协同）

- 房间列表：成员数 · 最新消息 · needs-you 徽标
- 房间内：多 agent 对话、`@成员`、`@user` 升级、线程回复

任务：T17.1（`groups.*` / `bot_relay.*`）。

| 分区 | 内容 | 任务 |
| --- | --- | --- |

| 渠道 | 消息平台列表 / 配置 / onboarding | T17.2 |
| **用量** | 会话/消息统计 + 按模型费用 | T10.1/T10.2 |
| **监控** | 健康 / 日志 / 指标 | T4.6/T11.2 |
| 记忆 | Memory provider / 重置 | T17.3 |
| Webhooks | 订阅管理 | T17.4 |
| 插件 | 插件列表 / 启停 | T7.5 |
| 数据与目录 | 工作区 / 文件根 / 配置中心 | T8.4/T11.1 |
| **系统升级** | **核心 + web 应用**：版本、检查更新、升级 | 顶栏升级灯同源 |
| 诊断与运维 | 健康 / 日志 / ops（doctor/backup/import） | T18.4 |
| 高级 | 本地模型 / 配对与设备 / 门户计费 / vault·connectors / browser·image·voice 开关 | T18.1–T18.15 |

## 7. 管理页（仅 super_admin）

| 分区 | 内容 | 任务 |
| --- | --- | --- |
| 用户与角色 | 列表/建/改/禁用/分配 profile/重置密码 | T3.1–T3.6 |
| 审计 | 操作审计查询 | T3.7 |
| 系统运维 | ops / 升级（可归此处） | T18.4 |

## 8. 右侧面板

- Tab：**文件 · 预览 · 日志 · Git**
- **图形按钮 ◧ 收起/展开**；默认**收起**，打开默认 tab = **文件**
- 隐藏不销毁（保留滚动/状态）

## 9. 响应式 / 移动端（T13.2）

- 窄屏：左轨折叠为图标条或抽屉；右面板转全屏页；会话列表与对话可切换。
- 顶栏精简为「菜单 · 核心灯 · 模型 · ◧」。

## 10. 功能 → 界面位置映射

| 任务组 | 界面位置 |
| --- | --- |
| M0 基线 | 不可见（工程） |

| M3 代理 | 不可见（顶栏核心灯/渠道状态可见） |
| M4 前端骨架 | 顶栏 + 左轨 + 右面板 + 登录页 |
| M5 对话 | 对话页 |
| M6 技能/工具/设置 | **智能体页（skill/toolsets/MCP）** + 设置（插件/模型/Keys/配置） |
| M7 任务/用量/面板 | 任务页 + **设置→用量/监控** + 右面板 |
| M8 Agent/Profile | 智能体页 |
| M9 体验 | 顶栏外观切换 / 全局文案 / 响应式 |
| M10 协作与集成 | **群聊页** + 设置（渠道/记忆/Webhooks） + 对话内子代理 |
| M11 运维与高级 | 设置 → 诊断运维 / 高级 / 系统升级；管理 → 系统运维 |
