# 界面设计与功能分布（UI）

> 目标：**chat-first 的中文工作台**，一级导航精简，配置/集成收入「设置」二级分区，⌘K 兜底全部功能。
> 参照：早期 24H DESKTOP 截图（顶栏 + 左轨 + 对话区 + 右面板 + 命令面板）。
> 功能来源：`docs/TASKS.md`（M0–M12）、`docs/INTERFACES.md`。

## 1. 总体布局

```
┌──────────────────────────────────────────────────────────────────┐
│ 24H  ● 核心 ready   ◦ 渠道 未连接     ⌘K   模型▾   面板  外观      │ 顶栏
├──────┬───────────────────────────────────────────┬───────────────┤
│ 对话 │  会话列表    │        对话区               │  文件          │
│ 智能体│  · 搜索      │  气泡 / 工具卡 / 审批卡      │  预览          │ 右面板
│ 技能 │  · 新建      │                             │  日志          │ (可收起)
│ 任务 │  · 重命名    │  ─────────────────────────  │  Git           │
│ 用量 │              │  Composer [附件][模型] 发送  │               │
│      │              │  上下文 18% · 62 tok/s      │               │
├──────┼───────────────────────────────────────────┴───────────────┤
│ 设置 │                                                           │
│ 管理*│   (* 仅 super_admin 可见)                                  │
└──────┴───────────────────────────────────────────────────────────┘
```

四个区域：**顶栏** / **左轨（一级导航）** / **主区** / **右侧面板**，外加全局 **⌘K 命令面板**。

## 2. 左轨（一级导航）

| 组 | 项 | 说明 |
| --- | --- | --- |
| 上 | **对话** | 默认落地页，chat-first |
| 上 | **智能体** | Agent/Profile：列表/创建/编辑/删除/头像 |
| 上 | **技能** | 技能列表/启停（能力入口） |
| 上 | **任务** | 定时任务（Cron） |
| 上 | **用量** | 会话/消息/模型费用统计 |
| 下 | **设置** | 配置与集成的二级入口 |
| 下 | **管理** * | 用户与角色、审计、运维（仅 super_admin） |

## 3. 顶栏

品牌「24H」· **核心状态**（ready/端口）· **渠道状态**（已连接/未连接）· **⌘K** · **模型选择器** · **面板开关**（右面板）· **外观**（主题/语言）。

- 核心状态 = BFF→Hermes 健康（T4.6）；断开时给降级提示。
- 模型选择器 = 当前会话/默认模型（T8.2），切换影响后续对话。

## 5. 页面功能分布

### 5.1 对话（T6.*）
- 左内栏：会话列表（搜索/新建/重命名/删除/恢复）— T6.1/T6.9
- 主区：transcript（`message.delta/complete`、`thinking`、工具卡 `tool.*`、`done/error`）— T6.3/T6.4/T6.8
- 交互卡：审批 `approval` / 澄清 `clarify` / `sudo`/`secret`/`mcp.setup` — T6.5/T6.6
- Composer：输入、**附件**（图片/文件/PDF）、模型、发送/停止 — T6.11/T6.7
- 断线重放：刷新后经 `session.events.since` 恢复挂起状态 — T6.10

### 5.2 智能体（T16.*，M8）
- 列表/详情（`profiles.list` / `/api/profiles`）— T16.1
- 创建/克隆（`profiles.create`）— T16.2
- 编辑：SOUL / 模型 / skills（`profiles.configure`）— T16.3
- 删除 / 导入导出 — T16.4
- 头像（`profiles.set_asset/get_asset`）— T16.5

### 5.3 技能（T7.*）
- 技能列表（按类别分组）+ 启停 — T7.1/T7.2
- 顶部 tab 或入口：**工具·Toolsets**（T7.3）· **MCP**（T7.4）· **插件**（T7.5）
  （也可归入「设置 → 能力」，见 §5.6；二选一，见 §9 待确认）

### 5.4 任务（T9.*）
- Cron 列表 + 新增/暂停/恢复/删除/立即运行

### 5.5 用量（T10.*）
- 概览卡片（会话/消息）+ 按模型 token/费用

### 5.6 设置（二级导航）

| 分区 | 内容 | 任务 |
| --- | --- | --- |
| 服务商与模型 | Keys / 模型 / MOA / OAuth | T8.1/T8.2 |
| 能力 | 工具·Toolsets / MCP / 插件 | T7.3/T7.4/T7.5 |
| 渠道 | 消息平台列表/配置/onboarding | T17.2 |
| 记忆 | Memory provider / 重置 | T17.3 |
| Webhooks | 订阅管理 | T17.4 |
| 外观 | 主题 / 语言 | T8.3 |
| 数据与目录 | 工作区 / 文件根 / 配置中心 | T8.4/T11.1 |
| 诊断与运维 | 健康 / 日志 / ops（doctor/backup/import） | T4.6/T11.2/T18.4 |
| 高级 | 本地模型 / 配对与设备 / 门户计费 / vault·connectors / browser·image·voice 开关 | T18.1–T18.15 |

### 5.7 管理（仅 super_admin）

| 分区 | 内容 | 任务 |
| --- | --- | --- |
| 用户与角色 | 列表/建/改/禁用/分配 profile/重置密码 | T3.1–T3.6 |
| 审计 | 操作审计查询 | T3.7 |
| 系统 | 运维 ops（可归此处） | T18.4 |

## 6. 命令面板（⌘K，T12.1）

- **导航**：任意一级页 / 设置分区 / 智能体直达
- **动作**：新建会话、切换模型、切换主题/语言、开关右面板、打开日志、复制诊断…
- 作用：让"功能多"不挤压导航——**导航只放主对象，长尾走 ⌘K**。

| 任务组 | 界面位置 |

| M5 对话 | 对话页 |
| M6 技能/工具/设置 | 技能页 + 设置 |
| M7 任务/用量/面板 | 任务页 + 用量页 + 右面板 |

| M12 未来 | 登录页（OIDC）/ 技能内（Skill UI） |

## 8. 响应式 / 移动端（T13.2）

- 窄屏：左轨折叠为图标条或抽屉；右面板变为可切换全屏页；会话列表与对话可切换。
- 顶栏精简为「菜单 · 标题 · 模型 · ⌘K」。
