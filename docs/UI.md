# 界面设计与功能分布（UI）

> 目标：**chat-first、简洁**的中文工作台。顶栏只放"状态 + 全局动作"；一级导航 ≤6；配置收进「设置」分组；面板默认收起。
> 依据：用户最终决策 —— 管理独立一级入口；一级名「群聊」；监控独立分区；升级不分开（核心+web 一起）；**偏好简洁**。

## 1. 设计原则（简洁）

1. **顶栏只放状态 + 全局动作**（核心灯 / 渠道 / 模型 / 外观 / 面板），不放导航。
2. **一级导航 ≤ 6 项**，图标 + 文字，可折叠为纯图标。
3. **设置用左侧分组列表**，一屏一区，不做卡片墙。
4. **面板/抽屉默认收起**，按需展开；隐藏不销毁。
5. **状态用「灯 + 极简文字」**，细节 hover 展开。
6. **不用命令面板**；高频动作放顶栏或就地。
7. **配色克制**：一个主色 + 中性色；日间/夜间两套。

## 3. 顶栏（极简）

| --- | --- |

| **核心灯** | `● v0.21.3`（颜色=状态：绿正常/黄告警/红断开）。hover 显示端口/详情；**点击 → 系统升级**（核心 + web 一起，不分开） |

## 5. 智能体页（含 per-agent 能力管理）

**列表**：每行 = 头像 · 名称 · 模型 · **版本灯** · 状态。
**操作**：打开对话 · 编辑 · 克隆 · 删除 · 导入/导出 · 新建。

**单个智能体管理（均 per-agent）**：SOUL（人格）· 模型/provider · Skills（启停）· MCP servers · 工具/Toolsets · **版本灯** · 头像。

任务：T16.1–T16.5、T7.1/T7.2、T7.3、T7.4。

## 6. 群聊页（多 agent 协同）

- 房间列表：成员数 · 最新消息 · needs-you 徽标
- 房间内：多 agent 对话、`@成员`、`@user` 升级、线程回复

任务：T17.1（`groups.*` / `bot_relay.*`）。

## 7. 任务页

Cron 列表 + 新增/暂停/恢复/删除/立即运行。任务：T9.1/T9.2。

## 10. 右侧面板

- Tab：**文件 · 预览 · 日志 · Git**
- **图形按钮 ◧ 收起/展开**；默认**收起**，打开默认 tab = **文件**
- 隐藏不销毁（保留滚动/状态）

## 11. 响应式 / 移动端（T13.2）

- 窄屏：左轨折叠为图标条或抽屉；右面板转全屏页；会话列表与对话可切换。
- 顶栏精简为「菜单 · 核心灯 · 模型 · ◧」。

## 13. 已定决策

- 管理 = **独立一级入口**（仅 super_admin）。
- 群聊一级名称 = **「群聊」**。
- 监控 = **独立设置分区**。
- 升级面板 = **不分开**（核心 + web 应用同一面板）。
- 去掉命令面板；外观 = 顶栏日/夜一键切换；右面板图形按钮收起。
